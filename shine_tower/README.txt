HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or use a local development server.
4. Internet access is needed for Bootstrap, Bootstrap Icons, Google Fonts and the externally hosted sample photographs.

CUSTOMIZE BEFORE PUBLISHING
1. Replace sample stock photos with Shine Tower's real completed project photographs.
2. Review the service list and remove any service not actually offered.
3. Update the email address in assets/js/main.js. The current sample uses info@shinetower.ae as a placeholder; confirm the correct company email.
4. The popup form appears on every page after a 9-second delay on the first page visit in a browser session. Visitors can also open it from the "Get a Quote" buttons.
5. The form currently prepares an email using the visitor's mail application (mailto). For direct website submissions, connect a backend or form provider and configure spam protection.
6. Add the company's approved logo, social links, privacy policy and any required licensing/business details.
