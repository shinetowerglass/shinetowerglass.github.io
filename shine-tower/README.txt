# Shine Tower Glass and Aluminium Works LLC SPC — Website Package

## Included
- 6 main pages: Home, About Us, Services, Projects, Blog, Contact
- 8 separate service detail pages
- English and Arabic versions (`/ar/`)
- Bootstrap 5.3 responsive layout
- Horizontal icon-based services mega-menu
- Floating WhatsApp and Call buttons on the right
- Back-to-top button on the left
- Enquiry popup on every page (opens after 18 seconds once per browser session; also opens from quote buttons)
- Contact forms route the enquiry to WhatsApp with the entered details

## Preview
Open `index.html` in a browser. For a local server, run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Before publishing
1. Replace the illustrative Unsplash photos with your actual project photographs.
2. Connect a production form backend or CRM if you want enquiries stored; the current form opens WhatsApp and does not store data.
3. Review service descriptions and legal/company details.
4. Upload the package contents to your hosting account / website root.
5. Update canonical URLs and sitemap/robots settings if the final domain structure differs.

Bootstrap, Bootstrap Icons and Google Fonts load from their CDNs, so internet access is required for those assets.
